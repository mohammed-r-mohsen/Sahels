# ساهل — Sahel Systems v4
منصة حجز مواعيد ذكية للعيادات (SaaS متعدد المستأجرين) مع واتساب وإنستغرام وبوابة ويب، مبنية على **Rust (Axum)** و **PostgreSQL (RLS)** و **Redis** و **Next.js**.

## التشغيل السريع

```bash
cp .env.example .env
docker compose up -d --build
curl http://localhost:8080/health
```

واجهة الويب (تطوير):

```bash
cd apps/web
npm install
npm run dev
```

قبل التشغيل، استبدل `JWT_SECRET` في `.env` بقيمة عشوائية لا تقل عن 32 بايت. لا تستخدم القيمة التوضيحية في الإنتاج.

قبل حفظ رموز WhatsApp أو Instagram، اضبط `INTEGRATION_ENCRYPTION_KEY` في `.env` إلى قيمة عشوائية آمنة لا تقل عن 32 بايت. تُشفّر رموز الوصول في PostgreSQL ولا تُعاد من API. احتفظ بنسخة آمنة من المفتاح؛ فقدانه يمنع فك تشفير الرموز المحفوظة. يحدد `OLLAMA_BASE_URL` عنوان Ollama على مستوى الخادم؛ القيمة الافتراضية `http://ollama:11434` مناسبة عند توفير خدمة Ollama بهذا الاسم على شبكة Docker.

## تسجيل عيادة جديدة

```bash
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d "{\"clinic_name\":\"عيادة النور\",\"slug\":\"alnoor\",\"email\":\"admin@alnoor.sa\",\"password\":\"Secret123!Sahel\",\"full_name\":\"مدير العيادة\"}"
```

## تذكير المواعيد عبر واتساب

يرسل عامل خلفي رسالة واتساب واحدة قبل الموعد بأربع ساعات، ويعيد المحاولة عند فشل Meta مع تأخير تصاعدي وحد أقصى خمس محاولات. يتطلب الإرسال ربط قناة واتساب فعالة لكل عيادة وقالبًا معتمدًا في Meta باسم `META_REMINDER_TEMPLATE`، مع ثلاثة متغيرات نصية في محتوى القالب (العيادة، التاريخ/الوقت المحلي، الطبيب) وثلاثة أزرار رد سريع بالترتيب: تأكيد الحضور، احتمال التأخر، والتواصل مع موظف. يجب أن يسمح القالب بتمرير payload للزر.

رد التأكيد يسجل حضور المريض المتوقع ويرسل إقرارًا. رد احتمال التأخر أو طلب الموظف يسجل التحويل في سجل المحادثة وسجل التدقيق، ويظهر في صندوق المحادثات داخل لوحة العيادة. لا يُلغى موعد المريض ولا يُحجز الموعد التالي من قائمة الانتظار تلقائيًا؛ يتم تحرير الفترة من خلال إجراء العيادة المعتاد، منعًا للحجز المزدوج. لا توجد مكالمات آلية في هذا المسار لتجنب رسوم الاتصالات الإضافية.

## تكاملات القنوات ونماذج الذكاء الاصطناعي

من إعدادات العيادة يمكن إدخال معرّف رقم واتساب ومعرّف حساب WhatsApp Business، ومعرّف حساب Instagram الاحترافي والصفحة المرتبطة، ورمز الوصول الخاص بكل قناة. تحفظ بيانات الربط في `clinic_channel_integrations` مع عزل RLS وتشفير رموز الوصول بواسطة `pgcrypto` باستخدام `INTEGRATION_ENCRYPTION_KEY`. تعرض واجهة القراءة المعرّفات وحالة وجود الرمز فقط؛ تحديث الرمز أو حذفه إجراء صريح.

يبقى `META_APP_SECRET` و`META_VERIFY_TOKEN` إعدادين عامين للـwebhook على مستوى الخادم، وليسا بيانات اعتماد لكل عيادة.

إعدادات Ollama خاصة بكل عيادة، مع `allam:7b` للعربية و`qwen2.5:7b` لتنظيم الحجوزات افتراضيًا. عنوان Ollama مركزي من إعداد الخادم (`OLLAMA_BASE_URL`) ولا يقبل عنوانًا من المستخدم. حفظ بيانات Instagram لا يعني أن استقبال رسائله أو إرسالها أصبح مدعومًا؛ يلزم استكمال webhook ومعالج القناة. كذلك إعداد النماذج لا يشغّل بوت الحجز تلقائيًا؛ مسار الذكاء الاصطناعي والموافقة المسبقة لم يكتمل بعد.
